家里的 IPTV 一直是我网络里最别扭的一环。光猫桥接、R5S 拨号之后，电视盒子要能看，手机和 iPad 也想在内网随时看直播。折腾到今天，方案基本定型：组播进来，单播出去，全家设备只认一个 `.m3u`。这篇把路径和坑记一下。

## 为什么不用双线

最省事的做法是 IPTV 走单独一条线，光猫另开一个 LAN 口给盒子。但它有个硬伤：只有机顶盒能看。想让 iPad 在客厅看球、想在书房用小窗挂着新闻，就没辙了。

所以我选的是单线方案：IPTV 的 VLAN 和上网走同一根线进 R5S，在设备里拆开。好处是一条线解决全部，代价是组播要在路由器上转一次。这一转，就是后面所有麻烦的来源。

## 环境

- 友善 R5S（RK3568，双 2.5G 口），4G 内存
- ImmortalWrt，版本跟着 snapshot 走，隔几个月更新一次
- 光猫桥接，R5S 上跑 PPPoE
- IPTV 侧走独立 VLAN，需要过 `option60` 认证才能拿到地址

`option60` 这块每个地区不一样，我的做法是在 `dhcp` 配置里给 IPTV 接口单独写一个带厂商标识的请求头。这一步没什么通用答案，抓包看光猫发给盒子的内容最直接。拿到地址之后，组播源就是 `239.x.x.x:端口` 这样的形式，能 ping 通但普通设备播不动——它只认 IGMP 加入。

## udpxy 的问题

第一版用的是 udpxy，配置简单，一个端口转发所有组播：

```
udpxy -p 4022
```

用起来是没问题，但用了半年后开始不舒服，主要是两点：

1. **单线程**。家里同时开电视 + iPad + 偶尔手机上再看一路，切台就卡。udpxy 一个进程串行处理，多路并发时缓冲会堆。
2. **日志没信息**。出问题只能看到连接数，不知道是哪一路在丢包。

R5S 本身性能不弱，瓶颈全在转发进程上。

## 换成 msd_lite

msd_lite 是 udpxy 的一个轻量替代，多线程、内存占用小，配置语法几乎一样。装好之后：

```
opkg install msd_lite
```

配置文件在 `/etc/config/msd_lite`，大致这么写：

```
config msd_lite 'msd'
    option enabled '1'
    option port '4022'
    option source '0.0.0.0'
    option loglevel '2'
```

日志级别我开到 2，这样能看到每一路 join/leave 和流量统计。切台卡顿时，直接看日志就知道是源的问题还是客户端的问题。

换完之后体感差别很明显：三路并发不再互相拖，CPU 占用从原来偶发的 30% 掉到个位数。R5S 这种小机器，省下来的每一分都值钱。

## 防火墙和 IGMP

这一步最容易漏。组播是 UDP，进来之后如果防火墙默认 DROP，客户端加入会静默失败——现象是 m3u 能加载、频道列表正常，点播放转圈。

需要放行：

- 从 IPTV 接口进来的 IGMP
- 组播网段到内网的转发
- msd_lite 监听端口的入站

我是给 IPTV 接口单独建了一个 zone，规则收敛在那里面，不动主 zone。这样以后调上网规则时不会被 IPTV 的例外干扰。

## EPG

单播地址解决的是"能不能看"，EPG 解决的是"看不看得下去"。没有节目单的直播列表，用两天就想卸载。

我的做法是定时抓节目单，转成 XMLTV，再拼进 m3u 的 `tvh` 字段。频道 ID 必须和节目单里的 `channel id` 严格对上，这里错一个字符，整个台就没节目名。我第一次配的时候就是 ID 大小写不一致，查了一晚上。

抓取脚本挂在 cron 上，每天凌晨跑一次，失败就重试三次。节目单这种东西不需要实时，延迟一天完全能接受。

## IPv6 那个反复出现的坑

IPTV 接口拿到的是动态 IPv6。重播之后地址变了，如果哪里写死了地址（比如某些转发的白名单），第二天就失效。

我的处理是让脚本在 `ifup` 之后读一次当前地址，写进临时配置，而不是硬编码。写完重载服务，不重启整个网络。这样拨号重连、断电恢复都不会出问题。

顺便说一句 WireGuard：我不想让 IPTV 的流量绕到外面去，所以在路由表里给组播和单播端口做了定向放行，走直连。默认路由该怎么样还怎么样，互不影响。

## 现在的状态

一套跑下来：光猫桥接 → R5S 拨号 → VLAN 拆 IPTV → msd_lite 转单播 → 全家一个 m3u。

稳定性大概是一个月需要看一眼日志，不需要动手。更新固件的时候要重新检查一遍防火墙 zone，因为 ImmortalWrt 大版本升级偶尔会重置自定义 zone。

这套方案不适合所有人。如果你只有一台电视、不折腾，双线最省心。但只要家里有第二块屏幕想看电视，单播这件事迟早要做，早点做比后面改省事。
